Introdução ao CSS

O CSS serve para separar a estrutura do site do seu design visual, permitindo controlar as cores, fontes, espaçamentos e o comportamento responsivo dos elementos em uma única folha de estilos independente.


O que é CSS?

Significa Cascading Style Sheets (Folhas de Estilo em Cascata). É uma linguagem de estilo usada para ditar a aparência e a estética dos elementos que foram estruturados através das tags do HTML.


Formas e Tipos de Aplicação

Existem diferentes maneiras de selecionar um elemento HTML e aplicar um estilo CSS sobre ele. Abaixo estão as quatro formas principais:


1. Aplicação Inline (Atributo style="")

Consiste em aplicar o estilo **diretamente dentro da tag HTML** utilizando a propriedade style. É recomendada apenas para testes rápidos ou exceções muito específicas, pois mistura estrutura com design. 

<p style="color: blue; font-size: 16px;">Este parágrafo será azul.</p>

2. Seleção por Tag

Seleciona e aplica a regra visual a **todas as tags idênticas** que existirem na página ao mesmo tempo. 

/* Altera todos os parágrafos do site */
p {
    color: green;
}

3. Seleção por Classe (Atributo class="")

Cria uma regra que pode ser **reutilizada em múltiplos elementos** diferentes da página. No HTML você usa o atributo class="nome-da-classe" e no CSS você a seleciona iniciando com um **ponto (.)**. 

<p class="texto-destaque">Texto importante.</p>
<span class="texto-destaque">Símbolo importante.</span>
/* CSS */
.texto-destaque {
    font-weight: bold;
    background-color: yellow;
}

4. Seleção por ID (Atributo id="")

Aplica o estilo a um **elemento único e exclusivo** da página. Dois elementos nunca devem compartilhar o mesmo ID. No HTML você usa o atributo id="meu-id" e no CSS você o seleciona iniciando com uma **hashtag (#)**. 

<button id="botao-enviar">Enviar</button>
/* CSS */
#botao-enviar {
    background-color: blue;
    color: white;
}

Hierarquia e Especificidade (A Cascata)

Quando duas ou mais regras CSS tentam mudar a mesma propriedade de um elemento (como definir cores diferentes), o navegador resolve o conflito seguindo uma **ordem estrita de peso e prioridade**:

A regra geral diz que **o seletor mais específico e direcionado sempre vence o mais genérico**. A ordem de peso, do mais forte para o mais fraco, é:

1. Inline (style=""): É o mais forte de todos. Ele ignora qualquer regra externa e aplica o estilo direto na tag.

2. ID (#): É muito forte por ser focado em um único elemento exclusivo da tela. Vence as classes e as tags.

3. Classe (.): Tem peso médio. Consegue vencer as regras genéricas aplicadas diretamente nas tags.

4. Tag: É o seletor mais fraco e genérico de todos, pois afeta elementos de forma global.


Regras para inicialização

  1. Crie uma pasta chamado "styles" dentro do projeto.
  2. Crie um arquivo chamado "main.css"
  3. Abra lado-a-lado a página que deseja estilizar e o arquivo css.
  4. Crie o estilo no arquivo css.
  5. Adicione a classe onde você quer aplicar o estilo no arquivo da página.
  6. Salve ambos arquivos e verifique a aplicação do estilo.
